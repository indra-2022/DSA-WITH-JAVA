# Backtracking & Recursion (Maze Problems)

This repository contains solutions to various Maze Problems implemented using Recursion, Backtracking and related algorithms.

## About Maze Problems

Maze Problems are among the most important and frequently asked DSA problems in coding interviews. They help build strong problem-solving skills and improve understanding of recursion, backtracking, matrix traversal, and graph traversal techniques.

These problems are commonly asked by product-based companies in coding rounds and technical interviews.

## Topics Covered

- Maze Path Finding
- Maze Path Count
- Maze with Obstacles
- Multi-Directional Maze Traversal
- Backtracking Based Maze Problems
- N-Queens 
- Sudoku Solver

## Concepts Used

- Recursion
- Backtracking
- 2D Arrays
- Matrix Traversal
- Graph Concepts
- Path Finding Algorithms

## Typical Problem Statement

Given a maze represented by a 2D grid, find a valid path, all possible paths, or the total number of paths from the source cell to the destination cell while avoiding blocked cells.

## Why Learn Maze Problems?

Maze problems help in understanding:

- Recursive thinking
- Backtracking techniques
- State space exploration
- Path finding strategies
- Matrix-based problem solving

They also serve as a foundation for advanced problems such as:

- Flood Fill
- Graph Traversal
- Knight's Tour

## Interview Relevance

Maze-related questions are frequently asked in product-based company interviews because they test:

- Logical Thinking
- Problem Solving Ability
- Recursion Skills
- Backtracking Knowledge
- Optimization Techniques
