# Object-Oriented Programming (OOP)

## 📖 About

Object-Oriented Programming (OOP) is **not an algorithm** or a data structure.

It is a **programming paradigm** (a set of principles and guidelines) that defines **how we should write and organize code for real-world applications**.

Instead of writing everything inside a single file or function, OOP helps us divide our program into **objects and classes**, making the code:

- Easier to understand
- Easier to maintain
- Reusable
- Scalable
- Closer to real-world modeling

Because OOP focuses on **designing programs**, the examples in this repository are intentionally **small and simple**. Each file contains only the minimum amount of code required to demonstrate a particular OOP concept.

---

## 🎯 Goal of this Repository

This repository is meant for learning the **core principles of Object-Oriented Programming**.

Although the programs are short, every example demonstrates one or more OOP concepts that are used in real-world software development.

## 📝 Note

Do not judge the examples by the number of lines of code.

OOP is about **how code is structured**, not how long it is. Even a program with only a few lines can demonstrate important OOP principles.

The concepts learned here are the same ones used to build large applications such as:

- Banking Systems
- E-commerce Applications
- Social Media Platforms
- Game Engines
- Enterprise Software
- Android Applications

## 🚀 Happy Learning!
